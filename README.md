# Monobank Exporter

Скрипт выгрузки банковских выписок ФОП из [Monobank](https://api.monobank.ua/) в CSV.
Поддерживает несколько клиентов, настраиваемый период и формат, удобный для открытия в Excel.

## Возможности

- Выгрузка по всем счетам клиента с типом `fop`.
- Несколько клиентов: у каждого свой токен и свой каталог.
- Период по умолчанию — предыдущий день; легко изменить в `config.kdl`.
- CSV с BOM и разделителем `;` — кириллица корректно открывается в Excel.
- Логи с причинами ошибок (HTTP-статус и тело ответа); токены не логируются.
- Ошибка одного клиента не прерывает выгрузку остальных.

## Требования

- Ruby 3.4.2 (см. `.ruby-version`)
- Bundler

## Установка

```bash
git clone https://github.com/SerzhKont/mono.git
cd mono
bundle install
```

## Настройка

Создайте рабочий конфиг из шаблона и заполните токены:

```bash
cp config.kdl.template config.kdl
```

`config.kdl` (файл в `.gitignore`, в репозиторий не попадает):

```kdl
settings {
  // Необязательно. Без этих строк выгружается предыдущий день.
  from "2026-09-01"
  to "2026-09-16"
}

clients {
  fop "Александренко Інна Михайлівна" token=ВАШ_ТОКЕН
  fop "Второй ФОП" token=ДРУГОЙ_ТОКЕН
}
```

Токен выдаётся в личном кабинете [api.monobank.ua](https://api.monobank.ua/).
Имя в кавычках (`fop "..."`) становится именем каталога для выгрузки.

### Период

- `from` и `to` — даты в формате `YYYY-MM-DD`, местное время; `to` включается целиком (до `23:59:59`).
- Указан только `from` или только `to` — выгружается один соответствующий день.
- Нет блока `settings` — выгружается предыдущий день.

## Запуск

```bash
bundle exec ruby mono.rb
```

Запускать из корня репозитория (иначе rbenv возьмёт другую версию Ruby).

## Результат

```text
export/<имя клиента>/<имя клиента>[_<метка счёта>]_<YYYY-MM-DD_HH-MM-SS>.csv
```

Метка счёта добавляется только тогда, когда у клиента несколько ФОП-счетов.

Колонки CSV: дата и время, описание, MCC, сумма, сумма в валюте операции, валюта,
комиссия, кешбэк, баланс, комментарий, контрагент, ЕДРПОУ, IBAN контрагента,
Receipt ID, Invoice ID, Hold, ID операции. Суммы переводятся из копеек в формат `0.00`.

Логи пишутся в `logs/export.log` (файл дописывается) и дублируются в консоль.

## Коды возврата

- `0` — все клиенты выгружены успешно.
- `1` — была хотя бы одна ошибка, в том числе отсутствующий или повреждённый
  `config.kdl`, либо в конфиге нет ни одного клиента с непустым именем и токеном.

## Ограничения API Monobank

- `client-info` и `statement` — не чаще 1 запроса в 60 секунд.
- Максимальное окно выписки — 31 день + 1 час; длинные периоды скрипт разбивает
  на части и выдерживает паузы между запросами.
- Ответ `429 Too Many Requests` не повторяется — попадает в лог как ошибка.

## Безопасность

Не коммитьте `config.kdl`, `export/` и `logs/`: там токены доступа, персональные
и финансовые данные. Эти пути уже перечислены в `.gitignore`.
